## Run in VS Code
1. Open this folder in Visual Studio Code.
2. Open Terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite (normally `http://localhost:5173`).

## Build for deployment
Run `npm run build`.

Note: `node_modules` is intentionally not included in the ZIP. Install dependencies with `npm install` on your Windows machine.
